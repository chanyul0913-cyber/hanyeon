# 合緣 합연 — 우리 사주 궁합 사이트

두 사람(나·상대 여자)의 **사주(四柱八字)** 를 계산해 **일주 기준 일별 속궁합·피크·합궁**을 보여 주는 비공개 정적 사이트.
`D:\AI로또`(luckylab)와 같은 구조: 정적 HTML+CSS+JS · 로컬 라이브러리 · PWA · GitHub Pages 배포 가능.

## 사용법

1. **비밀번호**: 기본 `0817` — 두 사람만 아는 것으로 바꾸려면 설정 모달 → "비밀번호 변경".
   (해시는 `js/app.js`의 `DEFAULT_PASS_SHA256` 또는 브라우저 localStorage에 저장)
2. **생년월일 설정**: 설정 모달에서 두 사람의 생년월일·시각 입력(양력/음력·윤달·시간 모름 지원).
3. **공유 링크**: 🔗 공유 버튼 → 생년월일이 담긴 URL 복사 → 상대가 열면 자동 채워짐(비밀번호는 별도 입력).
4. **탭**: 오늘(요약·향후 60일 피크일) / 명반(사주 8자·오행·대운) / 궁합 분석(일주×일주) / 일별 궁합(월 캘린더) / 서양 점성술(별자리·synastry).

## 해석 체계 (엔진 규칙)

- **합궁(✿)**: 그날 일간 오행이 여자 일간을 生하거나 같은 오행인 날(사주). 사주 합궁은 속궁합 점수 +8. 서양합궁(오늘의 달·금성이 그녀 출생 차트와 조화각만 이루는 날)은 표시용.
- **피크(⭐)**: 속궁합 점수 82점 이상.
- **속궁합 점수(0~100)**: 애정 동조(남자 재성=여자 관성일) + 천간합 + 지지 육합/삼합 − 충(−6)·형·원진·파·해 + 오행 유입 + 합궁(+8) + 용신일 + 도화/천을귀인
- **고정 궁합**: 일주×일주(천간합·지지 육합/충/형·오행 보완·도화 인연·12운성)
- 서울 태양시 30분 보정, 시간 모르면 시주 제외(6글자), 점수는 재미·소통용 근사치

## 유의

- 클라이언트 비밀번호 게이트는 URL 아는 사람의 캐주얼한 접근을 막는 수준이며, 서버 인증이 아니라 완전한 보안 장치가 아닙니다.
- 생년월일·시각은 각 브라우저(localStorage)에만 저장됩니다. 공유 링크에 생년월일이 포함되니 링크 전달에 유의하세요.
- 해석 결과는 전통 명리 규칙의 근사 구현으로, 재미와 소통용 참고자료입니다.
